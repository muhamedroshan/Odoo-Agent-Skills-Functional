# Company & Localization: Clarification Questions
Always review this area.

| # | Question | Why it matters | Default |
|---|---|---|---|
| C1 | Legal company name(s), address, tax/registration numbers, logo? | Documents, legal compliance | – |
| C2 | One company or several? Branches? | Multi-company setup, access rules | Single |
| C3 | Country of each company? | Localization package | – |
| C4 | User interface languages? Document/report languages (customer-facing)? | Installing languages, translations | English |
| C5 | Time zone(s)? | Scheduling, reports | Browser TZ |
| C6 | Odoo version and edition confirmed? Hosting: on-premise, Odoo.sh or Odoo Online? | Feasibility of customizations and Studio | Must ask |
| C7 | Expected number of users per type (internal, portal)? | Licensing, access design | – |
| C8 | Units of measure used (metric/imperial, custom units)? | UoM configuration | Metric |
| C9 | Outgoing/incoming email domain? Should the demo send emails? | Mail server; demo safety | Disabled in demo |
| C10 | Document branding (report layout, colours, footer)? | Document layout | Standard layout |
